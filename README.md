# Кліп — скіл для Claude Code, який нарізає довгі відео на шортси

Даєш стрім, подкаст чи ефір → отримуєш 3–7 вертикальних кліпів 9:16 з великими субтитрами, хуком зверху, назвою, описом і хештегами.
Усе працює на твоєму комп'ютері: відео нікуди не завантажується.

## Встановлення

У Claude Code напиши по черзі:

```
/plugin marketplace add burmistrovaalina1303-create/klip
/plugin install klip@klip
```

Або через npx:

```
npx skills add https://github.com/burmistrovaalina1303-create/klip
```

Потім напиши Claude: **«встанови скіл klip»** — він поставить ffmpeg, whisper і модель розпізнавання мови (один раз, ~10 хвилин).

## Як користуватись

Напиши **«наріж це відео на кліпи»** і перетягни файл або встав посилання.
Можна уточнити: «зроби 5 кліпів по 30 секунд», «тільки смішні моменти», «субтитри блакитні», «обріж на весь екран».

## Що вміє

| Крок | Що робить |
|---|---|
| Розшифровка | whisper.cpp розпізнає українську, англійську та інші мови; знає, коли звучить кожне слово, тому субтитри точно збігаються з голосом |
| Вибір моментів | Claude читає весь текст і знаходить 3–7 найсильніших шматків по 20–60 с з хуком на початку |
| Нарізка | ffmpeg робить 9:16 — розмитий фон або обрізка по центру |
| Субтитри | великі, по словах, з підсвіткою слова, що звучить |
| Опис | назва, опис і хештеги до кожного кліпу |

## Вимоги

- Mac (Apple Silicon або Intel) з Homebrew
- або Windows 10/11 з winget (встановлення для Windows — перша версія)
- ~2 ГБ місця

## Важливо

Кліпай тільки своє відео або те, на яке автор дав дозвіл (кампанії кліпінгу, партнерки). Скіл не гарантує заробіток чи перегляди: він економить години монтажу.
